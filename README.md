项目为智联招聘Python岗位数据可视化应用，使用Flask框架搭建，包含岗位数据爬取、分析与可视化功能。

## 功能模块
1. 数据爬取
- 使用spider/zhilian_python_spider.py爬取智联招聘Python岗位信息
- 支持城市维度数据采集（北京/上海/广州/深圳等）
- 保存岗位数据到本地文件

2. 数据分析
- 使用app.py进行数据处理与分析
- 统计企业类型分布
- 分析岗位城市分布
- 计算薪资水平分布

3. 数据可视化
- 创建企业类型分布饼图
- 生成城市岗位分布柱状图
- 绘制薪资水平箱线图
- 通过index.html展示可视化结果

## 文件结构
- app.py: 数据处理与Flask服务
- spider/: 爬虫模块
- templates/: 前端页面模板
- .csv文件: 存储分析结果数据
- .txt文件: 存储原始爬取数据

## 运行说明
1. 启动爬虫采集数据
2. 运行app.py处理数据
3. 访问Flask服务查看可视化结果

项目采用Python开发，依赖Flask框架，适合用于招聘数据分析和可视化展示。
